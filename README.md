# FokusFlow — Pomodoro Taymer (Netlify tayyor loyiha)

Ushbu arxiv **Netlify** (ham **Netlify Drop**, ham **GitHub -> Netlify** deploy) uchun to'liq moslashtirilgan.

## Netlify'ga yuklash:
1. Arxivni papkaga chiqaring (**Extract All...**).
2. Netlify saytidagi **Drop new files** (yoki **Sites -> Add new site -> Deploy manually**) oynasiga chiqarilgan papkani tashlang.
3. Sayt darhol ishga tushadi!
